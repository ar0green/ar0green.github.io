Проверочные скрипты (не нужны для работы сайта). Требуют Playwright с Chromium;
путь импорта `/opt/npm-tools/node_modules/playwright/index.mjs` замените на свой (`playwright`).
- `smoke.mjs [base]` — открывает ~30 адресов, печатает заголовки и ошибки страницы.
- `shoot.mjs base outdir width "имя=путь,…" [full] [json-прогресса]` — снимки экранов.
- `flows.mjs [base]` — сценарии: первый визит, этап→задача, сборка→мод→покупка→назад к слоту, ресурс→место,
  выполнение и перезагрузка, две вкладки, ошибка записи, неизвестный формат, хранилище запрещено.
- `shoot-ds.mjs` — снимки превью дизайн-системы для сравнения.
