# Навигатор Тенно

Локальный русскоязычный сайт-навигатор по Warframe, построенный по гайду
`guide/Warframe_Endgame_Guide_RU_v3.md` и дизайн-системе `design-system/`.
Новая реализация: предыдущие прототипы и каталоги проекта не использовались и не изменялись.

## Как открыть

**Вариант 1 — просто файл.** Откройте `index.html` двойным щелчком (или перетащите в окно браузера).
Адреса будут вида `index.html#!/stage/3`. Работает без интернета и без установки чего-либо.
Поиск по Wiki в этом режиме зависит от того, разрешит ли браузер запрос к wiki.warframe.com из файла;
если нет — сайт честно покажет ошибку и ссылку для поиска на самой Wiki.

**Вариант 2 — локальный сервер (рекомендуется).** Нужен Node.js 18+:

```bash
cd navigator-tenno-site
node tools/serve.mjs          # http://localhost:8080
node tools/serve.mjs 3000     # другой порт
```

Адреса будут обычными (`/stage/3`, `/mod/vitality`), кнопки «Назад/Вперёд» и обновление страницы работают.

## Пересборка после правок содержания

```bash
node tools/build.mjs
```

Скрипт читает гайд (`src/guide/…md`, либо `../guide/…md`) и содержание (`src/content/*.mjs`), проверяет
связи (ссылки на сущности, условия, источники, циклы требований, покрытие всех 22 разделов гайда,
сборки — 8 слотов и один ключевой мод) и записывает `assets/data.js` и `assets/app.js`.
При ошибке сборка останавливается и печатает, что не так.

## Арсенал: варфреймы, оружие, полярности

- Вкладки «Варфреймы» (25) и «Оружие» (30: основное, вторичное, ближний бой) — в шапке; на телефоне — «Арсенал» в нижней панели.
  Фильтры: роль/класс, способ получения, этап маршрута, ранг мастерства, наличие у вас.
- У каждого — соло-сборка (49 новых + 6 сборок гайда). Прайм-версия показана отметкой у базового: полярности, характеристики, хранилище.
- Полярности (Warframe Wiki, «Polarity»): мод в слоте своей полярности стоит вдвое дешевле (с округлением вверх),
  в слоте чужой — на 25% дороже; аура своей полярности даёт вдвое больше вместимости, чужой — 80%. Сайт раскладывает
  встроенные полярности так, чтобы стоимость была минимальной, и считает, сколько форм нужно — с Реактором/Катализатором и без.
  Слот эксилуса учитывается, только если отмечен адаптер эксилуса. Стойка ближнего боя в расчёт не входит (на странице есть пометка).

## Где хранится прогресс

Только в этом браузере на этом компьютере: `localStorage`, ключ `tn:progress:v1`.
Отметки, задачи, выбранный этап, настройки. Перенос — «Настройки → Экспорт / Импорт» (файл JSON).
Каждая запись проверяется чтением; если браузер не дал сохранить, изменение откатывается и показывается
ошибка, а не «Сохранено». Данные неизвестного формата не перезаписываются. Несколько вкладок синхронизируются.

Проверочные режимы (для разработки): `?debug=storage-fail`, `?debug=storage-off`, `?debug=wiki-fail`,
`?debug=wiki-slow`; сброс — `?debug=off`.

## Источники данных

Цены, ранги и условия, которые сайт показывает как факты, сверены с Warframe Wiki
(ссылка и дата проверки — у каждого факта). То, что взято только из гайда и не перепроверено,
помечено «по гайду». Данные из примеров дизайн-системы как игровые не используются.

## Ограничения

- Цены, ранги и условия сверены с Wiki на 12.10.2026; после обновлений игры их нужно перепроверять.
  Сведения только из гайда помечены «по гайду».
- Поиск по Wiki требует интернета; без сети показывается ошибка и ссылка на поиск на самой Wiki.
- Прогресс хранится только в этом браузере на этом устройстве (перенос — экспорт/импорт файлом).
- Шансы выпадения показаны там, где сверены; для остальных — «нет данных», а не выдуманные числа.
- Картинок предметов нет (используются значки дизайн-системы).
- Соло-сборки составлены сайтом из распространённых модов — это стартовая точка, а не единственно верный вариант;
  Гельминт, осколки архонта, мистификаторы и стойка ближнего боя в расчёт не входят.
- Если у способности нет проверенного русского названия на ru.wiki, показывается английское.
